## Forking into CodeSandbox

To fork this repository into CodeSandbox and start the development server, follow these steps:

1. Go to [CodeSandbox](https://codesandbox.io/).
2. Click on the "Create Sandbox" button.
3. Select the "Import Project" option.
4. Enter the GitHub repository URL: `https://github.com/JlCln/special-waddle`
5. Click on the "Import" button.
6. Once the project is imported, open the terminal in CodeSandbox.
7. Run the following command to start the development server:
   ```
   npm run sandbox
   ```

You should now be able to see the application running in the CodeSandbox preview.
